A growing collection of **flashcard decks** I've built while learning Spanish, kept in a repo as plain CSV rather than inside a single app, so they can be imported into
<a href="https://ankiweb.net" target="_blank">Anki</a>, Brainscape or anything else, and edited with the tools I already use.

There are two halves. The first is thematic vocabulary compiled by hand as I went – colours, animals, body parts,
professions, fruit and vegetables, adjectives, time and numbers – around 600 cards in total. The second is a set of
decks aligned to the <a href="https://www.languagetransfer.org" target="_blank">Language Transfer</a> audio courses,
split by course part rather than dumped into one file, so that a deck maps onto the tracks you've actually listened to
and you're never drilling vocabulary you haven't met yet. Each language folder carries its own lesson summaries
alongside the decks.

Deliberately boring by design: no app, no schema, no build step. Two columns of comma-separated text turn out to be a
remarkably durable format, and keeping it in Git means the decks survive whichever flashcard app I'm using this year.

This repo is also where <a href="https://language-transfer-companion.netlify.app/" target="_blank">Language Transfer
Companion</a> came from – once the decks and summaries existed for four languages, putting a website on top of them was
the obvious next step.
